Política de Privacidad

Última actualización: Septiembre 2026

1. Responsable del Tratamiento

El responsable del tratamiento de los datos recabados para la gestión de su cita es el negocio o profesional con el que usted interactúa. Tridev Soluciones actúa como Encargado del Tratamiento proveyendo la infraestructura técnica para la gestión de reservas.

Contacto para privacidad: tridevsoluciones@gmail.com.

2. Datos Recopilados

  • Datos identificativos: Nombre y número de teléfono (asociado a la cuenta de WhatsApp).
  • Datos de la reserva: Servicio solicitado, fecha, hora y profesional asignado. En citas sanitarias (clínicas dentales o fisioterapia), el servicio solicitado puede revelar indirectamente datos de salud con el único fin de reservar la consulta.
  • Datos técnicos y metadatos: Identificadores de mensaje necesarios para procesar la respuesta.

3. Finalidad y Base Jurídica

Tratamos sus datos para:

  • Gestión, confirmación y recordatorio de citas (Art. 6.1.b RGPD: ejecución de la relación de servicio).
  • Gestión asistencial bajo secreto profesional en centros sanitarios (Art. 9.2.h RGPD).

4. Subencargados del Tratamiento

Para prestar el servicio, los datos son procesados a través de los siguientes proveedores de infraestructura con las debidas garantías legales:

  • Meta Platforms Ireland Ltd.: Transmisión de mensajes mediante la API oficial de WhatsApp Cloud.
  • Google Ireland Ltd. / Google LLC: Sincronización y lectura de disponibilidad en Google Calendar.
  • OpenAI: Procesamiento automatizado de texto estructurado (sin uso de datos de usuarios para entrenamiento de modelos).
  • Supabase / Upstash: Alojamiento de bases de datos seguras y memoria temporal de disponibilidad.

5. Conservación de Datos

Los historiales de mensajería temporal se eliminan periódicamente tras la confirmación de la cita. Los datos de la reserva se conservan durante el tiempo necesario para cumplir con las obligaciones legales aplicables.

6. Derechos del Usuario

Puede solicitar el acceso, rectificación, supresión o limitación de sus datos enviando un correo a privacidad@tudominio.com o solicitándolo directamente al negocio responsable. Asimismo, puede presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).
