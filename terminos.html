1. Objeto y Ámbito de Aplicación

El presente documento regula el acceso, registro y uso de la plataforma tecnológica Tridev Soluciones (el "Servicio"), un software bajo modalidad SaaS (Software as a Service) diseñado para permitir a negocios, profesionales independientes y centros de servicios ("Clientes B2B" o "Tenants") automatizar la recepción de solicitudes, consulta de disponibilidad y confirmación de citas con sus respectivos usuarios finales ("Clientes Finales") mediante canales de mensajería instantánea y sincronización de agendas digitales.

2. Descripción de las Funcionalidades

Tridev Soluciones proporciona herramientas de software que incluyen:

  • Atención conversacional automatizada mediante la API oficial de WhatsApp Cloud de Meta.
  • Procesamiento estructurado de lenguaje natural para la interpretación de fechas y servicios solicitados.
  • Lectura y reserva bidireccional de disponibilidad contra cuentas externas de Google Calendar vinculadas individualmente por cada profesional.
  • Mecanismos de notificación y confirmación de agendas tanto para profesionales como para usuarios finales.

3. Cuentas y Conexión con Servicios de Terceros

Para la correcta prestación del Servicio, Tridev Soluciones interactúa con diversas plataformas externas:

  • Google Calendar API: El profesional o negocio autoriza a Tridev Soluciones el acceso a su calendario mediante el protocolo OAuth 2.0. Tridev Soluciones únicamente consulta eventos y disponibilidad de franjas libres y crea los eventos correspondientes a las citas confirmadas. Los datos de autenticación se almacenan con cifrado de seguridad en reposo.
  • Meta WhatsApp Cloud API: La transmisión y recepción de mensajes depende de la infraestructura técnica de Meta Platforms Ireland Ltd. El Cliente B2B debe aceptar las políticas de mensajería empresarial de Meta.

4. Obligaciones y Uso Aceptable

El usuario (tanto el negocio contratante como el cliente final que interactúa con el sistema) se compromete a:

  • Proporcionar información veraz, exacta y actualizada en las solicitudes de reserva.
  • No emplear el canal para el envío masivo de comunicaciones comerciales no solicitadas (spam), contenido difamatorio, ilegal o fraudulento.
  • No realizar técnicas de ingeniería inversa, inyecciones de código (prompt injection) ni intentos deliberados de vulnerar o sobrecargar los servidores o las bases de datos del sistema.
